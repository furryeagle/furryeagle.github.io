一、指標概念

吊燈停利（Chandelier Stop / Chandelier Exit）由 Chuck LeBeau 提出，是一種以波動度為基準的追蹤停利線。 它將停利點「掛」在近期高點或低點之下（上），就像吊燈懸掛在天花板一樣，隨著趨勢移動而自動跟隨，但絕不逆勢拉回。

多頭吊燈（Long Stop）

掛在近期最高收盤之下方 n×ATR 處，停利線只上不下，保護已實現的上漲利潤。

空頭吊燈（Short Stop）

掛在近期最低收盤之上方 n×ATR 處，停利線只下不上，保護已實現的下跌利潤。

核心優勢：市場波動大時，ATR 擴張，停利線自動拉開距離，不被假突破洗出場； 市場收斂時，ATR 縮小，停利線貼緊價格，及時鎖住獲利。

二、計算公式

步驟 1 — 計算吊燈距離

吊燈距離 = ATR(_period) × _mult

步驟 2 — 計算兩條停利線

多頭停利線 = Highest(Close, _period) − 吊燈距離　← 只能上調
空頭停利線 = Lowest(Close, _period) + 吊燈距離　← 只能下調

步驟 3 — 判斷趨勢方向

1
收盤 > 前一根空頭停利線 → 方向 = 多頭（+1）
2
收盤 < 前一根多頭停利線 → 方向 = 空頭（−1）
3
兩者都不成立 → 方向沿用前一根（趨勢延續）

步驟 4 — 輸出

多頭時：繪製多頭停利線（綠色）；空頭時：繪製空頭停利線（紅色）。

三、參數說明

參數 預設值 說明 調整建議
_period 22 ATR 計算期數，同時決定 Highest/Lowest 的回望窗口 日線建議 14–22；短線可縮至 10
_mult 3.0 ATR 倍數，決定停利線離價格的距離 越大越寬鬆；趨勢型策略建議 2.5–3.5

四、EasyLanguage 原始碼

1. 變數宣告區

// ──────────────────────────────────────────────
// 1. 變數宣告區
// ──────────────────────────────────────────────
input:
    _period(22, "ATR期數"),     // 看多長一段的波動度與高低點
    _mult(3.0, "ATR倍數");      // 吊燈離價格多遠，越大越鬆

var:
    _atrv(0),         // ATR * 倍數 = 吊燈距離
    _longstop(0),     // 多方停利線（只上不下）
    _shortstop(0),    // 空方停利線（只下不上）
    _dir(0);          // 趨勢方向：1=多, -1=空

2. 邏輯判斷區

// ──────────────────────────────────────────────
// 2. 邏輯判斷區
// ──────────────────────────────────────────────
_atrv = _mult * atr(_period);

// 多方停利線：近期最高(收盤) - 吊燈距離，且只能往上抬
_longstop = highest(close, _period) - _atrv;
if currentbar > 1 then begin
    if close[1] > _longstop[1] then
        _longstop = maxlist(_longstop, _longstop[1]);
end;

// 空方停利線：近期最低(收盤) + 吊燈距離，且只能往下壓
_shortstop = lowest(close, _period) + _atrv;
if currentbar > 1 then begin
    if close[1] < _shortstop[1] then
        _shortstop = minlist(_shortstop, _shortstop[1]);
end;

// 方向：突破空方線翻多、跌破多方線翻空，否則沿用
if currentbar = 1 then
    _dir = 1
else if close > _shortstop[1] then
    _dir = 1
else if close < _longstop[1] then
    _dir = -1
else
    _dir = _dir[1];

3. 腳本輸出區

// ──────────────────────────────────────────────
// 3. 腳本輸出區
// ──────────────────────────────────────────────
if _dir = 1 then
    plot1(_longstop, "多頭吊燈停利")
else
    noplot(1);

if _dir = -1 then
    plot2(_shortstop, "空頭吊燈停利")
else
    noplot(2);

五、關鍵邏輯細節

為什麼停利線要用 maxlist / minlist？

原始公式每根 K 線都重新算一次 Highest(Close, period) − ATR， 如果近期最高點發生在幾根前、之後收盤回落，新算出來的線反而會比上一根更低—— 這樣多方停利線就「往下拉」，違反「只保護不逆退」的原則。 用 maxlist(_longstop, _longstop[1]) 強制取兩者較大值，確保線只能上調。

方向判斷的條件順序

程式先判斷「收盤 > 前空頭停利線」，後判斷「收盤 < 前多頭停利線」。 若兩條件都不成立（收盤落在兩線之間，代表震盪整理），方向沿用前一根 _dir[1]， 避免頻繁切換訊號。

首根 K 線初始化

currentbar = 1 時強制 _dir = 1， 防止 _dir[1] 取到未初始化的 0 值造成輸出異常。

六、Pine Script v5 語法（TradingView）

Pine Script 的核心差異在於：用 var 宣告持久變數（跨 K 棒保留值）， 用 := 對它賦值；歷史參考 [1] 語意與 XS 相同。

// @version=5
indicator("吊燈停利 (Chandelier Stop)", overlay=true)

// ── 參數 ──────────────────────────────────────────────────
_period = input.int(22,  "ATR 期數", minval=1)
_mult   = input.float(3.0, "ATR 倍數", minval=0.1, step=0.1)

// ── 計算 ──────────────────────────────────────────────────
float _atrv = _mult * ta.atr(_period)

// 多方停利線（只上不下）
float _longstop_raw = ta.highest(close, _period) - _atrv
var float _longstop = na
_longstop := (not na(_longstop[1]) and close[1] > _longstop[1]) ?
             math.max(_longstop_raw, _longstop[1]) : _longstop_raw

// 空方停利線（只下不上）
float _shortstop_raw = ta.lowest(close, _period) + _atrv
var float _shortstop = na
_shortstop := (not na(_shortstop[1]) and close[1] < _shortstop[1]) ?
              math.min(_shortstop_raw, _shortstop[1]) : _shortstop_raw

// 趨勢方向
var int _dir = 1
_dir := barstate.isfirst          ? 1  :
        close > _shortstop[1]     ? 1  :
        close < _longstop[1]      ? -1 :
        nz(_dir[1], 1)

// ── 輸出 ──────────────────────────────────────────────────
plot(_dir ==  1 ? _longstop  : na, "多頭吊燈停利",
     color=color.new(color.green, 0), linewidth=2)
plot(_dir == -1 ? _shortstop : na, "空頭吊燈停利",
     color=color.new(color.red,   0), linewidth=2)
