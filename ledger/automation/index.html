通知自動記帳設定教學

流程：手機收到刷卡／付款通知 → MacroDroid 轉送 → 你自己的 Google 試算表 → 記帳網頁的「匯入紀錄」。約 15 分鐘，全部免費，資料只會經過你自己的 Google 帳號。

一、建立收件用的 Google 試算表

  1. 到 Google 雲端硬碟新增一份空白試算表，名稱隨意（例如「記帳通知」）。
  2. 選單「擴充功能 → Apps Script」，把編輯器裡原本的內容全部刪掉。
  3. 打開 Code.gs，全選複製、貼進編輯器。
  4. 把最上面的 KEY 改成你自己的一串亂碼（至少 20 個字元的英數字）。這就是金鑰，不要給別人。
  5. 右上角「部署 → 新增部署作業」，類型選「網頁應用程式」：
    • 執行身分：我
    • 誰可以存取：所有人
    按「部署」，第一次會要求授權，同意即可。
  6. 複製「網頁應用程式網址」，結尾是 /exec。

「所有人」是指不用登入 Google 就能呼叫這個網址，但沒有金鑰的請求一律會被拒絕。日後若改了程式，要到「部署 → 管理部署作業」編輯並選「新版本」才會生效。

二、在 MacroDroid 建立巨集

  1. 觸發條件：「裝置事件 → 通知 → 收到通知」。
    • 銀行：選擇應用程式勾「國泰世華 CUBE」「玉山 Wallet」（或你實際收到刷卡通知的 App），文字內容選「任何」。
    • LINE Pay：再加一個觸發條件，應用程式選「LINE」，文字內容選「包含」並填 付款。這個過濾一定要設，否則你的 LINE 聊天訊息也會被送進試算表。
  2. 動作：「網路 → HTTP 請求」。
    • 請求方法：POST
    • 網址：你的網頁應用程式網址?key=你的金鑰
    • 內容類型：text/plain
    • 內文：共三行，用輸入框旁的「…」（魔術文字）依序插入
      第 1 行「通知應用程式名稱」
      第 2 行「通知標題」
      第 3 行「通知文字」
    插入後看起來大致像這樣（實際符號以你的 MacroDroid 版本為準）： 
    [not_app_name]
[not_title]
[notification]
  3. 儲存巨集並開啟。到手機「設定 → 電池」把 MacroDroid 設為不受電池最佳化限制，否則背景可能收不到通知。

三、連結記帳網頁

  1. 打開「我的帳本 → 設定 → 通知自動記帳設定」，貼上網址與金鑰，按「儲存並測試連線」。
  2. 到「帳戶」把信用卡的卡號末四碼填好，通知才會自動對到正確的卡。
  3. 新增一個類型為「電子支付」、名稱含「LINE」的帳戶（例如「LINE Pay」），LINE Pay 的通知會記到這裡。

之後每次打開記帳網頁都會自動檢查新通知，放進「匯入紀錄」。你可以逐筆「新增」「修改後新增」「忽略」，或按「全部新增」。

目前看得懂的通知

  • 國泰世華刷卡通知：金額、末四碼、日期、商店。
  • 玉山信用卡消費通知：金額、末四碼、授權日期（民國年會自動換算）、商店名稱。
  • LINE Pay付款通知：金額、日期。通知裡沒有店家名稱，店家會先填「LINE Pay」，請用「修改後新增」補上。
  • 其他通知：只會盡量抓出金額，抓不到時顯示「無法辨識金額」，可手動修改或忽略。

測試與常見問題

  • 先測試：在 MacroDroid 巨集畫面按「測試動作」，試算表的「通知」工作表應該會多一列。
  • 試算表沒有新增列：檢查網址結尾是否為 /exec、?key= 後面的金鑰是否和程式裡的 KEY 完全相同。
  • 網頁顯示「金鑰不正確」：同上；如果改過 KEY，記得重新部署新版本。
  • 通知太多雜訊：在 MacroDroid 的觸發條件把文字內容改成「包含」特定字，例如 刷卡、消費。
  • 金鑰外流了：改掉程式裡的 KEY 並重新部署，再更新 MacroDroid 與記帳網頁的設定。
